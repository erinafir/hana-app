# 🌸 Hana App - Simple Fashion E-commerce

A beginner-friendly e-commerce project built while learning Next.js and web development fundamentals. Hana App showcases fashion apparel with basic e-commerce features.

## ✨ Simple Features

- 👕 Browse fashion products
- 🔍 Basic search functionality
- ❤️ Add items to wishlist
- 🔐 Simple user authentication
- 📱 Responsive design

## 🛠️ Learning Tech Stack

### Frontend
- Next.js (learning SSR concepts)
- Basic TypeScript
- Tailwind CSS for styling
- Simple React components

### Backend & Database
- Basic MongoDB integration
- Simple JWT authentication
- Basic API routes

## 🚀 Setup for Development

1. **Get Started**
```bash
git clone [url-repositori]
cd hana-app
npm install
```

2. **Run Development Server**
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## 📁 Basic Project Structure
```
hana-app/
├── src/           # Main source code
├── public/        # Static files
└── pages/         # Next.js pages
```

> 💡 **Learning Notes**: This project was created as part of a web development learning journey, focusing on a basic understanding of Next.js and simple e-commerce.

> 🌱 **Development Stage**: This is a learning project, still in the basic development stage and open for improvement.
